\section{布尔代数}

\subsection{数的编码与表示}

\de[二进制]{
	\tboba{二进制}是基数为2，只有两个数码0和1的数制。二进制数中，每一个数码称为一个二进制\tboba{位（bit）}，权值最小的二进制位称为\tboba{最低位（LSB）}，权值最大的二进制位称为\tboba{最高位（MSB）}。
}

二进制数的\tboba{左移}运算和\tboba{右移}运算分别是将二进制数的所有位向左或向右移动一位，移动后的空位补0。左移一位相当于乘2，右移一位相当于除2。

8个二进制位称为一个\tboba{字节}（byte，B），16个二进制位称为一个\tboba{字}（word）。在计算机中，字节是最小的可寻址内存单元，字是处理器的数据宽度。

\subsubsection{二进制自然数的特殊编码}

\de[BCD码]{
	\tboba{BCD（binary-coded decimal）码}是二进制编码的一种，用4位二进制数表示一个十进制数的一位。
	
	\tboba{8421 BCD码}的编码规则是：用二进制数的0-9的编码表示十进制数的0-9，不使用二进制数的10-15的编码。
}

由于 8421 BCD码是\textbf{有权码}，其加减法运算可以直接使用二进制数和十进制数的加减法运算规则。

\begin{example}[3]
	（1）\(34_{10} + 45_{10} = 0011\,0100_{BCD} + 0100\,0101_{BCD} = 0111\,1001_{BCD} = 79_{10}\)。

	（2）\(14_{10} + 9_{10} = 0001\,0100_{BCD} + 0000\,1001_{BCD} = 0001\,1101_{BCD} \xlongequal{\text{进位}} 0010\,0011_{BCD} = 23_{10}\)。
\end{example}

\de[Gray 码]{
	\tboba{Gray 码}是二进制编码的一种，保证了相邻两个数码之间只有一位的差异。
}

Gray 码将在 \ref{Sec: Combinational Logic Circuit Design} 节中使用 Carnot 图进行简化时发挥重要作用。

\subsubsection{二进制整数的编码}

\de[有符号原码]{
	\tboba{有符号原码}是整数二进制编码的一种，在给定位数的二进制数中，用最高位表示符号，0表示正数，1表示负数。
}

有符号原码是一种非常直接、适于人类理解的编码方式，但是其不满足按位进行加减法运算的规则。为了实现按位加减法运算，有必要引入补码和反码。

\de[2-补码]{
	\tboba{2-补码}是整数二进制编码的一种，用于表示有符号整数用于运算。正数的2-补码与原码相同，负数的2-补码是其绝对值的原码按位取反后加1。
}

\begin{example}[3]
	（1）将 \((-3)_{10}\) 转为2-补码形式：

	已知 \(3_{10} = 011_{2} = 011_{2's}\)，按位取反得到 \(100\)，则\((-3)_{10} = 101_{2's}\)。

	（2）将 \(101_{2's}\) 转为十进制数：

	将 \(101_{2's}\) 字面对应于3位无符号数 \(101_{2} = 5_{10}\)，则 \(101_{2's} = 5_{10}- 2_10^{3_10} = -3_{10}\)。
\end{example}

不考虑溢出的情况下，2-补码的加减法运算与无符号数的加减法运算规则相同，并能在规定的位数中连接正负侧形成循环。这样，二进制减法就可以通过按位取反运算和加法运算来实现。

\de[溢出]{
	在二进制加减法运算中，如果运算结果超出了规定的位数范围，则称为\tboba{溢出}。
}

加法的溢出只可能发生在同号两数相加时，其中两个正数相加得到负数（或零）的情况称为\tboba{上溢}，两个负数相加得到正数的情况称为\tboba{下溢}。从按位加法的角度来判断是否发生溢出，只需检查最高位的\textbf{进位输入} \(C_\mrm{in}\) 和\textbf{进位输出} \(C_\mrm{out}\) 做异或运算。根据进位输入、输出判断溢出的规则如表~\ref{Tab: Overflow}~所示。

\subsubsection{布尔代数}

\de[布尔代数]{
	\tboba{布尔代数}是一套使用逻辑运算符 \(\{\mrm{NOT}(\neg，')，\mrm{AND}(\land，+)，\mrm{OR}(\lor，-)\}\) 对定义在二元逻辑域 \(\{0，1\}\) 上的逻辑变量进行运算的代数系统。
}

\begin{theorem}
	布尔代数的基本定律有：
	\begin{description}[leftmargin=4em, parsep=0pt, itemsep=0pt]
		\item[交换律（Commutative Law）] \(X + Y = Y + X\)，\(X \cdot Y = Y \cdot X\)；
		\item[结合律（Associative Law）] \((X + Y) + Z = X + (Y + Z)\)，\((X \cdot Y) \cdot Z = X \cdot (Y \cdot Z)\)；
		\item[分配律（Distributive Law）] \(X \cdot (Y + Z) = X \cdot Y + X \cdot Z\)，\(X + Y \cdot Z = (X + Y) \cdot (X + Z)\)；
		\item[吸收律（Absorption Law）] \(X + X \cdot Y = X\)，\(X \cdot (X + Y) = X\)；
		\item[互补律（Complement Law）] \(X + X' = 1\)，\(X \cdot X' = 0\)；
		\item[幂等律（Idempotent Law）] \(X + X = X\)，\(X \cdot X = X\)；
		\item[对合律（Involution Law）] \((X')' = X\)。
	\end{description}
\end{theorem}

\begin{theorem}
	\textup{\textbf{一致性定理（Consensus Theorem）}}\quad \(X \cdot Y + X' \cdot Z + Y \cdot Z = X \cdot Y + X' \cdot Z\)，\((X+Y) \cdot (X'+Z) \cdot (Y+Z) = (X+Y) \cdot (X'+Z)\)。
\end{theorem}

\di[De Morgan 定律]{
	对布尔逻辑函数取反，等价于原函数的反演。即
	\[\overline{X + Y} = X' \cdot Y'，\qquad \overline{X \cdot Y} = X' + Y'\]
}

De Morgan 定律可用于变换逻辑函数的形式，由此可以将逻辑电路的形式转换为只用某一部分逻辑门实现的形式。

\begin{example}[3]
	将 \(Y = AB'C'+A'C+BC\) 转写为只用与非门实现的形式。

	\begin{solution}
		根据 De Morgan 定律有
		\begin{equation*}
			Y  = AB'C'+A'C+BC
			= \overline{\overline{AB'C'} \cdot \overline{A'C} \cdot \overline{BC}} \qedhere
		\end{equation*}
	\end{solution}
\end{example}

\begin{definition}
	在 \(n\) 变量的逻辑函数中，如果一个\textbf{与项}包含了所有 \(n\) 个变量或者它们的反且只包含一次，那么这个与项称为\tboba{最小项}，记作 \(m_i\)，其中 \(i\) 是一个 \(n\) 位二进制数，每一位对应于一个变量，0 或 1 表示变量在最小项中取反或不取反。
\end{definition}

\begin{definition}
	在 \(n\) 变量的逻辑函数中，如果一个\textbf{或项}包含了所有 \(n\) 个变量或者它们的反且只包含一次，那么这个或项称为\tboba{最大项}，记作 \(M_i\)，其中 \(i\) 是一个 \(n\) 位二进制数，每一位对应于一个变量，0 或 1 表示变量在最大项中取反或不取反。
\end{definition}

两级逻辑的表达式标准但不简单，我们希望能够通过简化逻辑表达式来简化逻辑电路。简化逻辑表达式的常用方法是\textbf{Carnot 图}法。

\subsubsection{组合逻辑电路的设计过程}

\label{Sec: Combinational Logic Circuit Design}

设计一个组合逻辑电路，需要将算法转化为二元逻辑的计算，化简后用逻辑电路结构实现。

\begin{example}[3]
	设计一个 2-bit 比较器。
	\begin{solution}
		2-bit 比较器的设计需求为：
		\begin{itemize}
			\item 功能：比较两个 2-bit 二进制数的大小；
			\item 输入：两个 2-bit 二进制数 \(A_1A_0\) 和 \(B_1B_0\)；
			\item 输出：三个逻辑值 \(LT\)、\(EQ\) 和 \(GT\)，分别表示 \(A < B\)、\(A = B\) 和 \(A > B\)。
		\end{itemize}
		用卡诺图表示出 \(LT\)、\(EQ\) 和 \(GT\) 的逻辑表达式如表~\ref{Tab: 2-bit Comparator}~所示，即知其两级与或表达式为
		\begin{align*}
			& LT = A_1'B_1 + A_1'A_0'B_0 + A_0'B_1B_0 \\
			& EQ = A_1'A_0'B_1'B_0' + A_1'A_0B_1'B_0 + A_1A_0'B_1B_0' + A_1A_0B_1B_0 \\
			& GT = A_1B_1' + A_1B_1'B_0' + A_1A_0B_0'
		\end{align*}
		其中 \(EQ\) 可以更简单地表示为
		\[
			EQ = \overline{A_1 \oplus B_1} \cdot \overline{A_0 \oplus B_0}
		\]
		或者利用另外两个输出的逻辑表达式，即
		\[
			EQ = \overline{LT + GT}
		\]

如上 4-bit 输入的逻辑运算已经比较复杂。对于更加复杂的逻辑运算，在处理中需要采取更多的技巧以简化运算，如：
\begin{itemize}
	\item 将输入变量分组，写成更简单的逻辑表达式的多级运算：
	\[
		f(A，B，C，\cdots) = F(g_1(A，B，\cdots)，g_2(C，\cdots)，\cdots)
	\]
	\item 将输入变量分离，写成更简单的逻辑表达式的分支计算：
	\[
		f(A，B，C，\cdots) = A \cdot g_1(B，C，\cdots) + \overline{A} \cdot g_2(B，C，\cdots)
	\]
	\item 从结构化表达式中找出重复的部分加以复用，简化逻辑电路。
\end{itemize} 
同时，还需要照应到实际的功耗、性能、面积等要求。

\subsubsection{组合逻辑电路的评价指标}

评价逻辑电路的主要指标包括：
\begin{itemize}
	\item 稳态因素：
	\begin{itemize}
		\item \textbf{逻辑电平}：逻辑电路的输入和输出电平高低；
		\item \textbf{噪声容限}：逻辑电路抵抗噪声的能力；
		\item \textbf{静态功耗}：逻辑电路在稳态工作时的功耗，主要与电路的 \(V_{CC}\) 有关；
		\item \textbf{面积}：逻辑电路的物理尺寸；
		\item \textbf{扇出系数}：逻辑门的输出能够驱动的输入数量。
	\end{itemize}
	\item 动态因素：
	\begin{itemize}
		\item \textbf{传输延迟}和\textbf{时钟频率}：逻辑电路的输入到输出的延迟时间；
		\item \textbf{时序容限}：逻辑电路的输入信号的时序要求；
		\item \textbf{动态功耗}：逻辑电路在工作时的功耗，主要与电路的切换频率有关；
		\item \textbf{噪声}：逻辑电路在工作时产生的噪声。
	\end{itemize}
\end{itemize}

RCA 的加法计算是串行的，每一步计算依赖于前一步的进位输出。但实际上，后续的进位输入可以直接从输入计算得到，多个进位输入可以并行计算。这种设计称为\tboba{超前进位加法器（carry look-ahead adder，CLA）}。

\begin{example}[3]
	设计一个 4-bit 超前进位加法器。
	\begin{solution}
		某一位运算的进位输出要么直接在本位生成，要么从前一位计算的进位输出传播过来。
		因此，定义\textbf{进位生成} \(G_i = A_iB_i\)，\textbf{进位传播} \(P_i = A_i \oplus B_i\)，
		那么每一级的 \(C_{i+1} = G_i + P_iC_{i}\)，\(S_i = P_i \oplus C_{i}\)。
		利用 \(G_i\) 和 \(P_i\) 递推计算，可得各位的进位为
		\begin{align*}
			& C_1 && = G_0 + P_0C_0 &&\\[-3pt]
			& C_2 && = G_1 + P_1(G_0 + P_0C_0) &&= G_1 + P_1G_0 + P_1P_0C_0 \\[-3pt]
			& C_3 && = G_2 + P_2(G_1 + P_1G_0 + P_1P_0C_0) &&= G_2 + P_2G_1 + P_2P_1G_0 + P_2P_1P_0C_0\\[-3pt]
			& C_4 && = G_3 + P_3(G_2 + P_2G_1 + P_2P_1G_0 + P_2P_1P_0C_0) &&= G_3 + P_3G_2 + P_3P_2G_1 + P_3P_2P_1G_0 + P_3P_2P_1P_0C_0
		\end{align*}
		4-bit 超前进位加法器的设计如图 \ref{Fig: 4-bit Carry Look-ahead Adder} 所示。
	\end{solution}
	\begin{figure}[!ht]
		\centering
		\includegraphics[scale=0.25]{Circuits/FIG-4-bit_Carry_Look-ahead_Adder.drawio.png}
		\caption{4-bit 超前进位加法器}
		\label{Fig: 4-bit Carry Look-ahead Adder}
	\end{figure}
\end{example}

超前进位加法器的本质是通过预先计算进位，用空间（面积）换时间（延迟），提高了加法器的运算速度。当计算到 \(i > 4\) 时，\(G_i\)、\(P_i\) 计算 \(C_{i+1}\) 的表达式会非常复杂，因此超前进位加法器一般只超前计算到 4 位。

\subsection{时序逻辑}

\subsubsection{时序逻辑电路的基本概念}

\paragraph{触发与节拍信号}

用\textbf{时钟信号}控制逻辑电路的运行，使其在时钟信号的\textbf{节拍}下按照一定的顺序依次\textbf{触发}响应进行逻辑运算，这种电路称为\tboba{时序逻辑电路}。

\begin{definition}
	\tboba{时钟信号发生器}是一种能够产生连续的方波信号的电路。
\end{definition}

用\textbf{奇数个}反相器可以串联成环形振荡器，若串联的反相器个数为 \(n\)，每个反相器的延迟时间为 \(t_\mrm{pd}\)，则环形振荡器的周期为 \(T = 2n \cdot t_\mrm{pd}\)。因此，环形振荡器是一种简单的时钟信号发生器。

\begin{example}[3]
	\label{e.g: Ring Oscillator}
	三个非门串联成环形振荡器，其中每个非门的上升延迟时间为 \(t_\mrm{pd} = 2t\)，下降延迟时间为 \(t_\mrm{pd} = t\)，如图 \ref{Fig: Ring Oscillator Example} 所示。
	求环形振荡器的周期、占空比。

	\begin{figure}[!ht]
		\centering
		\subfloat[电路]{
			\label{Fig: Ring Oscillator Example}

		}
		\quad

				\toprule
				\textbf{时刻/}\(\symbf{t}\) & \textbf{0} & \textbf{1} & \textbf{2} & \textbf{3} & \textbf{4} & \textbf{5} & \textbf{6} & \textbf{7} & \textbf{8} & \textbf{9} \\
				\midrule
				\(Q_1\) & * & * & 1 & 1 & 1 & 1 & 1 & 0 & 0 & 0 \\

		\[
			T = 3 \times (2t + t) = 9t

		\begin{equation*}
			\mrm{Duty\ Cycle} = \frac{t_{\mrm{high},Q_3}}{T} = \frac{4t}{9t} = 44.4\%
			\qedhere
		\end{equation*}
	\end{solution}
\end{example}

基于时钟信号，在边缘（如上升沿）采样输入信号、更新状态，可以实现时序逻辑。

\begin{definition}
	使信号事件与时钟节拍一致的操作称为\tboba{同步}，所有同步于同一个时钟信号的信号集合称为\tboba{时钟域}。
\end{definition}

\paragraph{状态与有限状态机}

一个系统的\tboba{状态（state）}应包含所有需要的信息而可以有冗余信息。依据输入信号和当前状态，系统的输出信号和下一个状态是确定的。

\de[有限状态机]{
	\tboba{有限状态机（finite state machine，FSM）}是一种能够根据输入信号和当前状态，确定输出信号和下一个状态的系统。

	描述一个 FSM 需要确定 6 大要素：
	\begin{itemize}[leftmargin=2em, topsep=0pt]
		\item 状态集合 State，FSM 的所有可能状态；
		\item 初始状态 \(S_0\)，FSM 启动及复位时的状态；
		\item 输入信号 Input；
		\item 输出信号 Output；
		\item 输出函数 \(f\)，描述 FSM 的输出信号与输入信号和当前状态的关系；
		\item 状态转移函数 \(g\)，描述 FSM 的下一个状态与输入信号和当前状态的关系。
	\end{itemize}
}

FSM 有两种类型：\tboba{Moore FSM} 和 \tboba{Mealy FSM}。Moore FSM 的输出只与当前状态有关，而 Mealy FSM 的输出与当前状态和输入信号有关。两种 FSM 的状态转移函数 \(g\) 都可以用\tboba{状态转换表（state transition table）}表示，如表~\ref{Tab: General State Transition Table}~所示；或者用\tboba{状态转换图（state transition diagram）}表示，如图~\ref{Fig: General State Transition Diagram}~所示。

\paragraph{触发器}
　
\de[触发器]{
	\tboba{触发器（flip-flop）}是一种\textbf{只在触发沿}把输入信号写入输出信号的电路。
}

\bu[D 触发器（DFF）]{
	\(\vcenter{\hbox{
		\includegraphics[scale=0.25]{Circuits/FIG-D_Flip-Flop.drawio.png}

}

DFF 的一种常见的实现方式是两个 D 锁存器级联，如图~\ref{Fig: D Flip-Flop Circuit}~所示，其中左侧的 D 锁存器用于存储输入信号，称为\tboba{主锁存器}；右侧的 D 锁存器用于控制输出信号，称为\tboba{从锁存器}。

	\centering
	\subfloat[逻辑电路]{
		\label{Fig: D Flip-Flop Circuit}
		\includegraphics[scale=0.25]{Circuits/FIG-D_Flip-Flop_Circuit.drawio.png}
	}\\
	\subfloat[时序图]{
		\label{Fig: D Flip-Flop Timing Diagram}
		\includegraphics[scale=0.25]{Circuits/FIG-D_Flip-Flop_Timing_Diagram.drawio.png}
	}
	\caption{D触发器}
\end{figure}

在一个时钟周期中，时钟信号 \(C\) 为低电平时，主锁存器的输出信号 \(Q_M\) 随输入信号 \(D\) 变化，从锁存器的输出信号 \(Q\) 保持不变；时钟信号 \(C\) 为高电平时，主锁存器的输出信号 \(Q_M\) 保持不变，从锁存器的输出信号 \(Q\) 将 \(Q_M\) 的值输出。因此，在 \(C\) 的上升沿，DFF 表现为将输入信号 \(D\) 写入输出信号 \(Q\) 锁存一个周期。DFF 的时序图如图~\ref{Fig: D Flip-Flop Timing Diagram}~所示。

\zhu[DFF 的时序参数]{
	DFF 的时序参数与锁存器类似，包括：
	\begin{itemize}[leftmargin=1em]
		\item \tboqi{建立时间} \(\mboqi{t_{\mrm{su}}}\)：输入信号在时钟信号上升沿前需要传输到 \(T_2\) 两端以避免竞争，这一过程所需要保持的时间；
		\item \tboqi{保持时间} \(\mboqi{t_{\mrm{h}}}\)：输入信号在时钟信号上升沿后需要维持到 \(T_1\) 完全关闭以避免破坏写入的值，这一过程所需要保持的时间；\\
		\(D\)和\(C\) 传播到 \(T_1\) 的时间一般相等，因此通常原生满足保持时间约束，即 \(t_{\mrm{h}} = 0\)。
		\item \tboqi{输出响应时间} \(\mboqi{t_{\mrm{c-q}}}\)：输入信号在时钟信号上升沿后到输出信号发生变化的时间。
	\end{itemize}

	当两个 DFF 级联时：
	\begin{itemize}[leftmargin=1em]
		\item 第一个 DFF 的输入信号 \(D_1\) 在开始采样 \(t_{\mrm{c-q}}\) 时间后才会传输到其输出 \(Q_1\)，第二个 DFF 的输入信号 \(D_2\) 在开始采样前 \(t_{\mrm{su}}\) 时间内需要保持不变，因此留给中间的组合逻辑电路的时间为 \(t_{\mrm{cyc}} - t_{\mrm{c-q}} - t_{\mrm{su}}\)，逻辑计算必须在这段时间内完成，这称为\tboqi{建立时间约束}；
		\item 第一个 DFF 的输出信号 \(Q_1\) 在 \(t_{\mrm{c-q}}\) 时间后才会更新，经过组合逻辑电路后才传输到 \(D_2\)，此前 \(D_2\) 因前一次采样而需要保持不变 \(t_{\mrm{h}}\) 时间，因此组合逻辑电路的延迟时间不能小于 \(t_{\mrm{h}} - t_{\mrm{c-q}}\)，这称为\tboqi{保持时间约束}。
	\end{itemize}	
}

\subsection{通用处理器的基本结构}

\subsubsection{算法与指令的实现}

\de[指令集]{
	\tboba{指令集（instruction set）}是一组用于控制计算机操作的指令的集合。
}

从众多软件算法中抽象出一组指令，是计算机的基本设计思想之一。算法指令的基本类型有：
\begin{itemize}
	\item \textbf{赋值操作}：将一个值赋给一个变量；
	\item \textbf{算术操作}：加、减、乘、除、求余等；
	\item \textbf{逻辑操作}：与、或、非、异或等；
	\item \tboba{分支跳转}：根据条件跳转到不同的指令；
	\item \tboba{直接跳转}：无条件跳转到指定的指令；
	\item \tboba{过程调用}：保持本组指令的执行现场，跳转到指定的过程执行，执行完毕后返回；
	\item \tboba{访存操作}：从内存中读取数据、向内存中写入数据。
\end{itemize}
要支持通用算法，指令集需要包含上述基本类型的指令。

其中：

	\item \tboba{算术/逻辑单元（ALU）}：执行算术、逻辑操作；
	\item \tboba{寄存器堆（REG）}：存储数据，提高访存速度。
\end{itemize}

\begin{definition}
	\textup{\textbf{普林斯顿架构}\quad}在普林斯顿架构中，存储器同时存储指令和数据，CPU处理器包括控制单元和计算单元（ALU）。

	\textup{\textbf{哈佛架构}\quad}在哈佛架构中，指令存储器和数据存储器分开，CPU处理器包括控制单元、指令存储器和数据存储器。
\end{definition}

\subsubsection{程序的执行流程}

\paragraph{数据的存储格式}

计算机中使用0/1二进制序列表示数据和指令。在指令集架构中，对数据和指令的存储格式有以下的要求：
\begin{itemize}
	\item 数据\textbf{按行存储}，以字节为单位索引，每个地址对应1字节数据；对于多字节数据，需要规定\tboba{字节序}——
	\begin{itemize}
		\item \tboba{大端序}：高位字节存储在低地址，如 0x12345678 存储为 0x12 0x34 0x56 0x78；
		\item \tboba{小端序}：高位字节存储在高地址，如 0x12345678 存储为 0x78 0x56 0x34 0x12。
	\end{itemize}
	\item 指令\textbf{按字存储}，以字为单位索引，每个地址对应1字指令。
\end{itemize}

\paragraph{汇编语言}

\de[汇编语言]{
	\tboba{汇编语言（assembly language）}是一种将机器指令翻译成易于理解的符号指令的语言。
}

汇编语言的基本元素包括：
\begin{itemize}
	\item \textbf{指令}：对应机器指令；
	\item \textbf{寄存器}：用于存储数据；
	\item \textbf{标号}：用于标记指令的地址；
	\item \textbf{伪指令}：用于定义数据、宏等。
\end{itemize}

\paragraph{指令集的性能评价}

指令集的性能主要是指其时间性能，有以下几个指标：
\begin{itemize}
	\item \textbf{指令数}：完成一个任务所需的指令数；
	\item \textbf{CPI（cycles per instruction）}：每条指令的平均时钟周期数；
	\item \textbf{时钟周期}：计算机时钟信号的周期；
	\item \textbf{执行时间}：完成一个任务所需的时间，等于\(\text{指令数} \times \text{CPI} \times \text{时钟周期}\)；
	\item \textbf{总时间}：包括执行时间和存取时间。
\end{itemize}
